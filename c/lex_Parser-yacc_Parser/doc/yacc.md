# How to use command `yacc` 





Q : How to use command yacc ?

A :

`yacc` (Yet Another Compiler Compiler) is a tool that generates parsers based on a given grammar specification. Parsers generated by `yacc` are usually used in conjunction with `lex`-generated lexers to form a complete compiler or interpreter for a language.

Here's a step-by-step guide on how to use `yacc`:

1. **Write a Yacc Specification**: Create a file, typically with a `.y` extension, containing the grammar specification for the language you want to parse. This file contains rules defining how to recognize sequences of tokens and what actions to take when those sequences are recognized.

    For example, a simple yacc file `calc.y` might look like:
    ```yacc
    %{
    #include <stdio.h>
    %}

    %token NUMBER

    %%

    expr:   expr '+' expr    { printf("%d\n", $1 + $3); }
        |   expr '-' expr    { printf("%d\n", $1 - $3); }
        |   NUMBER           { $$ = $1; }
        ;

    %%

    int main() {
        yyparse();
        return 0;
    }
    ```

2. **Generate the Parser**: Run `yacc` on the input file to generate the C code for the parser.
    ```bash
    yacc -d calc.y
    ```
    This command will produce files `y.tab.c` and `y.tab.h`.

3. **Compile the Parser**: Compile the generated C code using a C compiler like `gcc`.
    ```bash
    gcc y.tab.c -o parser -ly -ll
    ```
    The `-ly` option links against the `liby` library, and the `-ll` option links against the `libl` library (if a lexer generated by `lex` is also used).

4. **Generate the Lexical Analyzer (if needed)**: If you have a separate lexer generated by `lex`, you can compile it and link it with the parser. First, generate the lexer:
    ```bash
    lex calc.l
    ```
    Compile the generated C code:
    ```bash
    gcc lex.yy.c -o lexer -ll
    ```

5. **Run the Parser**: Execute the generated parser (and lexer, if used together).
    ```bash
    ./parser
    ```
    (or `./lexer` if you have a separate lexer)

6. **Provide Input**: Once the parser (and lexer) is running, you can provide input to it, and it will parse the input according to the grammar specified in the yacc file.

Note: This is a basic example to demonstrate the usage of `yacc`. Writing grammars and building parsers can be complex tasks that require careful design and testing. The combination of `lex` and `yacc` is powerful and is often used to build compilers and interpreters for programming languages.
